## @dataclass的作用
标准库模块，底层后续再解析
主要作用是：
1. 自动生成 __init__ 方法（构造函数）
你不需要再手动写 def __init__(self, name, price): self.name = name ...。加了这个装饰器，类变量声明直接变成构造函数的参数。

> **GPT 修正**：准确说是“被 dataclass 识别的字段”进入生成的 `__init__`；`ClassVar` 不作为字段，`InitVar` 只作为初始化参数，`field(init=False)` 也不会成为构造参数。未注解的普通类属性不会自动成为 dataclass 字段。

2. 自动生成 __repr__ 方法（易读的字符串输出）
当你打印这个类的实例时，不会再显示内存地址（如 <__main__.Product at 0x1a2b3c>），而是会清晰显示出该实例的所有属性值，方便调试。

3. 自动生成 __eq__ 方法（比较逻辑）
当你比较两个实例是否相等时，不再是比较内存地址，而是比较它们的属性值是否全部相同。

> **GPT 修正**：默认 `eq=True` 生成的比较只接受**相同具体类**，并按声明顺序比较 `compare=True` 的 dataclass 字段；动态添加的实例属性和 `compare=False` 字段不参与。未实现值相等协议时的默认行为更准确地说是基于对象身份，而不是承诺“比较内存地址”。
