# 类的数据校验

python 无论是在类里声明注解（x: int = 5）还是@dataclass + 声明注解，都只是约定，做不到真正的数据校验。可以通过数据描述符做到。

pydantic.BaseModel 底层就是通过 数据描述符 做到的
也可以自己手写实现

## @dataclass的作用
标准库模块，底层后续再解析
主要作用是：
1. 自动生成 __init__ 方法（构造函数）
你不需要再手动写 def __init__(self, name, price): self.name = name ...。加了这个装饰器，类变量声明直接变成构造函数的参数。

2. 自动生成 __repr__ 方法（易读的字符串输出）
当你打印这个类的实例时，不会再显示内存地址（如 <__main__.Product at 0x1a2b3c>），而是会清晰显示出该实例的所有属性值，方便调试。

3. 自动生成 __eq__ 方法（比较逻辑）
当你比较两个实例是否相等时，不再是比较内存地址，而是比较它们的属性值是否全部相同。
