## 注意事项

一般来说对象我们实例化时不会提前给这个str，int或者具体的一个对象先设置好 __set__ 和 __get__ 再传入的，一般是再写一个工具去使其成为`数据描述符` ，需要注意的是 `数据描述符` 不是类本身或者类的一个特性。它是其内部需要校验或者需要其他手段的属性需要的，写一个描述符类，创建它的实例放进类的 __dict__，替代原来的裸属性是对象本身的需求，而非类的需求。（这个对象是类里面的属性）.

### 为什么不在初始化时校验数据 或者 写类似java 写set，get方法呢？
本质都是约定，类的成员没有private这些关键字，本质都是可以通过 A.x访问的。只有通过`数据描述符`（最高优先级）可以实现更深层次的需求。
比如:当我们定义了一个类后，初始化可能是通过外部api传入的，我们需要这个类被实例化后修改或者赋值时做一些操作（也是看具体的需求，需要可靠地控制读写时），这时候就可以通过数据修饰符实现。
可能不一定要用到数据描述符，但是了解有这么个东西还是有用的。
（因为数据描述符的主流作用：类型验证和只读属性 也可以靠我们编写代码时约定 + 外部创建前校验。不一定用到，但是需要知道有这个东西）

# 原理学习
__set__ , __set__ 和 __del__ 我自己写设置时是固定的入参，因为python底层调用时固定传入：

__get__(self, obj, owner)       # Python 调：__get__ (描述符对象自己，实例, 类对象本身)
__set__(self, obj, value)       # Python 调：__set__ (描述符对象自己，实例, 新值)
__delete__(self, obj)           # Python 调：__delete__(描述符对象自己,实例)

```python
class Strict:
    def __get__(self, obj, owner):
        return obj.__dict__.get('_age', 0)

    def __set__(self, obj, value):
        if value < 0:
            raise ValueError('不能为负')
        obj.__dict__['_age'] = value

    def __delete__(self, obj):
        raise RuntimeError('age 不允许删除')

class Student:
    age = Strict()

s = Student() # 这里，self是 Strict， obj 是a， owner是 Student
s.age = 25
print(s.age)        
del s.age           
```
